# Checkpoint agent entry point

Checkpoint is a pnpm monorepo: `apps/api` (Node API), `apps/web` (React), `packages/core` (domain contracts), `packages/ui-react` (product-agnostic UI kit).

## Before you change anything

1. Open [[AI/index]] and follow the link for the area you will touch (backend, frontend, core).
2. Read the note that answers your task (a how-to for creating things, a reference for facts). Follow its `## Related` links only when you need more.
3. Run `pnpm check` before you finish.

## While you work: grow the knowledge graph

The notes in `AI/` form an Obsidian graph. Keep it connected, small and true:

- **Edit an existing note** when it already answers the same question as your new knowledge.
- **Create a new note** when the question or the note type differs, or when an existing note passes 150 lines.
- **Link both ways**: link the new note from its hub, and end it with a `## Related` section.
- Full rules and the note template: [[AI/documentation-rules]].
